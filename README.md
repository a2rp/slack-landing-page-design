# Slack Landing Page Design

A responsive React and Vite landing page inspired by modern collaboration products. It presents a workspace preview, feature sections, a responsive navigation menu, and a clear sign-up call to action.

![Slack landing page preview](screenshot.png)

## Features

- Responsive fixed header with mobile menu
- Workspace preview, trust strip, feature cards, progress section, and CTA
- Local logo and hero assets
- React Icons for interface actions and footer links
- Floating go-to-top control and dynamic copyright year

## Tech stack

- React and Vite
- CSS
- React Icons

## Run locally

```bash
npm install
npm run dev
```
